# Document Attribution Rule

## The Rule

Every financial document in a client matter folder is attributed by **the name actually printed on the document** — not by the folder it sits in, not by the filename, and not by an inference about which party "should" own it.

This rule is non-negotiable in Cowork financial work. Misattributing a single document at the FA-build stage cascades into Section I income errors, Section II expense errors, ED chart misallocations, and ultimately a flawed MSA.

## Why This Goes Wrong

Three common failure modes:

1. **Folder bias.** A document sits in `Lisa Limbaugh / DISCO - CLIENT / IRS Forms` so the assumption is "this is Lisa's." But the matter folder routinely holds joint returns, mandatory disclosure copies, and statements pulled from joint records. The folder location proves nothing about ownership.

2. **Filename bias.** A file named `Civilian W2.pdf` looks generic but the W-2 inside is in the spouse's name. A file named `Mil Ret 1099.pdf` looks like military retirement income but the recipient is the spouse, not the client.

3. **Multiple-choice deference.** When asked "are these docs Lisa's or Thomas's?" the human may answer "Lisa's" because they're being asked at speed, but the document itself answers the question definitively. Always open and check.

## How to Apply

For each document in the discovery folder before populating any FA line:

1. Open the document.
2. Look at the recipient field, employee field, account holder field, or beneficiary field.
3. Read the full legal name printed there.
4. Attribute accordingly.

If the document is a joint instrument (joint 1040, joint deed, joint account "OR" listing), note it as joint and break out the spouse-specific portions (W-2 wages by SSN, 1099s by recipient name, account holdings by who actually owns it under the joint title).

## Worked Examples (Limbaugh Matter)

| Document | Folder | Filename | What's printed on it | Correct attribution |
|----------|--------|----------|----------------------|---------------------|
| W-2 from Defense Finance & Acctg Serv, $170,269.70 | `Lisa Limbaugh / 5.6.26 / IRS Forms` | `Civilian W2.pdf` | Employee: THOMAS LEE LIMBAUGH | Thomas — does NOT go on Lisa's FA |
| 1099-R from DFAS Military Retired Pay, $53,167.90 | Same | `Mil Ret 1099.pdf` | Recipient: THOMAS L LIMBAUGH | Thomas — does NOT go on Lisa's FA |
| SSA-1099, $14,592.00 | Same | `2025 ssa-1099_ssa-1042s-letter.pdf` | Box 1 Name: LISA M LIMBAUGH | Lisa — goes on Lisa's Line 4 |
| 2025 1040 Joint | Same | `2025-Return.pdf` | (T) THOMAS L LIMBAUGH and (S) LISA M LIMBAUGH, MFJ | Joint — read line by line, attribute each income line to (T) or (S) |
| USAA Checking statement #2324 | `5.6.26 / Bank Statements` | balance $27,182.09 | Holders: THOMAS L LIMBAUGH OR LISA LIMBAUGH | Joint "OR" — list as joint asset |
| USAA Checking statement #1664 | Same | balance $3,238.46 | Holder: LISA LIMBAUGH | Lisa's sole — list as Wife sole |
| USAA Savings statement #2316 | Same | balance $2,221.89 | Holders: THOMAS L LIMBAUGH OR LISA LIMBAUGH | Joint — list as joint asset |

In the Limbaugh matter, three of these documents (the joint 1040 reading, the W-2, and the 1099-R) require attribution discipline that a quick "everything in this folder is Lisa's" pass would get wrong.

## When the Case Profile and the Document Conflict

When the project instructions or case profile says one thing (e.g., "client has no earned income — VA disability + SSDI only") and the discovery folder contains an apparently inconsistent document (e.g., a W-2), do not assume the case profile is wrong. The much more common explanation is that the document belongs to the spouse and was pulled from joint files. Open the document and confirm.

If the document genuinely is the client's and contradicts the case profile, that is a flag for the supervising attorney — not a green light to silently override the profile.
